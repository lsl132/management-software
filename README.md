# 管理软件

这是一个基于Spring Boot的管理软件，旨在提供高效企业的管理和监控功能。该软件具有以下功能：


### 系统模块
提供了对软件的核心功能进行管理和配置的模块，包括用户管理、权限管理等。


### 人事模块
提供了对企业员工信息进行管理的模块，包括员工档案、考勤管理、薪资管理等。


### 财务模块
提供了对企业财务信息进行管理的模块，包括财务报表、预算管理、费用报销等。

### 采购模块
提供了对企业采购流程进行管理的模块，包括供应商管理、采购订单管理、库存管理等。

### 销售模块
提供了对企业销售流程进行管理的模块，包括客户管理、销售订单管理、销售报表等。

### 技术栈
- Spring Boot
- MyBatis plus
- PostgreSQL
- Redis
